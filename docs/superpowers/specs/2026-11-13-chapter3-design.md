# 제3장 「잠긴 왕도」 설계

작성: 2026-11-13 · 기준 문서: `SAGA.md` (전체 구상), `README.md` (데이터 형식)

## 1. 의도

1·2장에 이어 이야기를 이어 간다. 이 장의 몫은 세 가지다.

- **오르덴 이야기의 끝.** 맹세기사단이 왜 돌이 되었는지, 오르덴의 동생 카이론과 왕 아우렐에게 무슨 일이 있었는지 드러나고, 오르덴의 맹세가 끝난다 (떠남·남음·쓰러짐).
- **2장의 선택이 돌아온다.** 리네·브리타를 구했는지, 세나·브란·오르덴의 처지, 이르반에게 한 대답, 잿불의 대군주 계약이 문장·전투·동료를 바꾼다.
- **동료가 넷을 넘는 첫 장.** 브리타·리네가 합류하면서 일행이 최대 셋으로 제한되고, 누구를 데려갈지 고르는 일이 생긴다. (사용자가 고름: **최대 셋**)

플레이어 레벨은 8에서 시작해 10쯤에서 끝난다 (`SAGA.md`의 레벨 계획).

## 2. 목표 · 하지 않을 것 · 실패

**목표**
- 2장과 같은 규모: 장소 6~7곳, 이야기·동료·야영·탐색 사건 40여 개, 새 적 15종 안팎, 우두머리 셋 (중간 우두머리, 장 우두머리, 사냥터 우두머리).
- 2장이 남긴 플래그마다 3장에서 무언가 달라진다 (아래 4절의 표).
- 동료의 운명표 3장 칸 (`SAGA.md` 4절)을 모두 이야기로 만든다.
- 새 동료 브리타·리네. 일행 최대 셋과 고르는 화면.
- 사냥터 우두머리, 모든 직업용 세트 하나, 소환사 3장 세트·기술서 (계획 표대로).
- 장 끝 기록 (3장 요약)과 4장으로 넘어가는 안내.

**하지 않을 것**
- 4·5장 내용. 3장은 4장으로 넘어가는 문을 열어 두기만 한다.
- 새끼({pup})를 전투 동료로 만드는 일 — 3장에서는 이야기와 야영 대화에만 나오고, 전투 동료는 4장(어미와 재회)으로 미룬다. *(제 판단: 동료가 이미 다섯이라 여섯째는 화면과 균형을 무너뜨린다)*
- 1·2장 균형을 다시 맞추는 일.

**실패로 치는 것 (돌아가더라도)**
- 2장에서 한 선택이 3장에서 아무 차이도 만들지 않는다.
- 플레이어가 막혀서 장을 끝낼 수 없는 길이 있다 (동료가 모두 죽거나 떠난 경우 포함). 2장처럼 **동료 없이 혼자서도** 끝까지 갈 수 있어야 한다.
- 평범한 길(대군주 아님)로 레벨 8~10에서 장 우두머리를 이기기 어렵거나, 반대로 1~2라운드에 끝난다.
- 일행 제한 때문에 이야기 전투에 꼭 있어야 할 동료가 빠져 이야기가 어긋난다.

## 3. 무대와 흐름

새 지역 **북쪽 호숫가** (`region: 'north'`). 회색 여울에서 북쪽으로 올라간다.

| 장소 (id) | 레벨 | 열리는 때 | 무엇이 있나 |
|---|---|---|---|
| 갈대 나루 (`reedferry`) | 안전 | 3장 시작 | 쉼터·상점·여관(야영 대화). 가라앉은 왕도의 후손들, 뱃사공 노인. 깨어나는 곳 |
| 거울 호수 (`lake`) | 8~9 | 시작 | 물뱀·물안개 망령·낙인 수병. 밤이면 호수에 비친 도시가 진짜가 된다 |
| 물의 문 (`watergate`) | 8~9 | 호수에서 내려갈 길을 찾은 뒤 | 별빛 장막 아래 가라앉은 성문. 사슬 사제의 진지 |
| 아우렐리아 하층 거리 (`lowcity`) | 9 | 물의 문을 지난 뒤 | 돌이 된 시민, 유령 기사, 사슬 사냥개 |
| 맹세의 전당 (`oathhall`) | 9~10 | 하층 거리에서 | 맹세기사단의 석상, 카이론, 오르덴의 결말 |
| 왕의 서고 (`archive`) | 9~10 | 하층 거리에서 | 낙인 기록, 카델의 첫 단서, 사냥터 우두머리의 봉인 금고 |
| 왕좌의 방 (`throne`) | 10 | 전당과 서고를 지난 뒤 | 가라앉은 왕 아우렐의 메아리 (장 우두머리), 두 번째 조각 |

**큰 줄기 (주 사건)**
1. `c3_start` 회색 여울을 떠나 북쪽으로. 2장 결말에 따라 함께 떠나는 사람이 다르다.
2. `c3_ferry` 갈대 나루 도착. 뱃사공 노인 하벨: 호수 아래 왕도 이야기, 사슬 사제 일행이 먼저 내려갔다는 소식. 브리타·리네가 이곳에서 합류한다 (5절).
3. `c3_lake` 거울 호수 — 내려갈 길: 밤의 호수에 비친 도시로 걸어 들어가려면 고요의 조각과 유물을 함께 비추어야 한다 (판정·아이템·동료로 여러 길: 고요의 조각으로 비추기 / 뱃사공의 종 / 세나·리네의 물길 읽기 / 맹세기사의 문장(오르덴·성기사)).
4. `c3_watergate` 물의 문 — **중간 우두머리 사슬 사제 데인**과 그의 사냥개. 데인은 카델을 섬기는 '사슬의 사제단' 사람으로, 아우렐의 메아리를 깨워 조각을 가져가려 한다. 2장에서 바스크의 믿음이 흔들렸다면(`vask_doubt`) 바스크가 데인을 배신하고 돕는 장면이 있다.
5. `c3_lowcity` 하층 거리 — 돌이 된 시민들. 낙인과 다른 '맹세의 돌'. 뱃사공의 딸을 돌에서 깨우는 곁가지 부탁.
6. `c3_oathhall` 맹세의 전당 — 진실: **아우렐이 이르반을 버렸다.** 별이 떨어진 밤 왕은 조각을 얻으려 이르반을 불길 속에 남겨 두고 문을 닫게 했고, 그 명령을 집행한 것이 맹세기사단이다. 기사들은 그 죄를 지키려(잊지 않으려) 스스로 돌이 되었다. 카이론은 문을 닫기를 거부한 단 한 사람이었다 — "사슬 위에 세운 평화는…"(2장의 말)이 그의 말이었다. 이어서 **오르덴의 결말** (6절).
7. `c3_archive` 왕의 서고 — 낙인의 첫 기록: 쉼(고요)을 뒤틀어 뜻을 덮는 법이 카델의 목소리에서 왔다는 첫 단서. 브란이 있으면 해독(판정 유리), 브란의 처지에 따라 갈린다 (6절).
8. `c3_throne` 왕좌의 방 — **장 우두머리: 가라앉은 왕 아우렐의 메아리.** 데인이 반쯤 깨워 둔 채로 남아 있다(데인을 물의 문에서 막았느냐에 따라 메아리가 약하거나 강하다). 결전의 특수 행동: 고요의 조각으로 메아리의 왕관을 가라앉힌다 (2장 결전들과 같은 방식).
9. `c3_judge` 메아리를 심판한다: 죄를 묻는다 / 용서한다 / 이르반에게 대신 사과하게 한다 (`aurel_judged_*`). 두 번째 조각(`shard2`) — 증폭 주사위 d10 → d12.
10. `c3_shadow` 이르반의 그림자가 다시 나타난다 (증폭 주사위는 조각을 얻을 때 `amp: { die: 12 }`). 2장 대답(`irvan_offer_*`)과 이번 심판에 따라 대화가 다르다. 다음 조각은 별의 첨탑(4장).
11. `c3_after` 에필로그와 3장 요약.

|---|---|
| `brita_saved` | 브리타가 갈대 나루에서 합류할 수 있다 (브란의 처지에 따라 다름, 5절) |

| `anchor_broken` / `ford_freed` | 회색 여울 사람들이 갈대 나루에 배와 식량을 보내 준다 (상점 할인·물약) |

| `hunter_mark` | 왕도에서 낙인 기록이 그대를 알아본다: 판정 하나가 불리, 대신 서고의 숨은 방이 열린다 |
| `pup_named` | 야영 대화와 탐색에 {pup}이 나온다 (전투 동료 아님) |
| `ember_lord` | 왕도의 석상 사제들이 손등의 왕관을 알아본다. 물의 문이 두려움으로 열리거나(쉬운 길), 전당의 기사 석상들이 칼을 뽑는다(대군주 전용 전투). `azra_evolved`면 아즈라칸이 카이론의 석상 앞에서 말을 꺼낸다 |
| `ember_refused` | 봉인지기의 맹세 장신구가 있으면 전당의 석상들이 그대를 같은 편으로 여긴다 (판정 유리) |
| 1장 `orden_joins` | 오르덴이 북쪽까지 함께 올 수 있다 (없으면 관문에 남아 있고, 3장에서 그를 데려오는 방법이 하나 있다: 관문으로 돌아가 왕도 이야기를 들려준다) |

## 5. 새 동료와 일행 제한

**브리타** (풀려난 낙인 채석꾼, 앞열)
- 2장 채석장에서 돌을 나르던 브란의 누이. 커다란 채석 망치를 든다.
- 기술: Lv1 돌 깨기 (넘어뜨림), Lv1 낙인 끊기 (아군 하나의 속박·약화 해제, 보조), Lv9 채석장의 함성 (아군 모두 명중·피해), Lv12 닻돌 내려치기 (한 열 힘 내성, 넘어뜨림).
- 합류: `brita_saved`. 브란이 함께면 남매가 같이 다니겠다고 하고, 브란이 적이 되었거나 죽었으면 브리타가 그대를 원망해 합류 여부가 판정·선택으로 갈린다 (운명표).
- 호감 `ap_brita`, 떠나는 선, 야영 대화 둘.

**리네** (세나의 어머니, 추적자, 뒷열)
- 2장의 회색 눈의 추적자. 낙인에서 풀려났다.
- 기술: Lv1 두 발 쏘기 (한 대상에 두 번), Lv1 추적자의 표식 (약점 노리기, 보조), Lv9 그림자 화살 (맞으면 얼어붙음), Lv12 네 번째 화살 (큰 한 방, 치명 범위 넓음).
- 합류: `rine_freed`. 세나가 적이 되었으면 리네가 세나를 말리러 따로 움직인다 (운명표).
- 호감 `ap_rine`, 떠나는 선, 야영 대화 둘.

**일행 최대 셋**
- 동료는 최대 셋까지 함께 다닌다 (`SC.partyCap = 3`). 1·2장은 동료가 셋을 넘을 수 없어서 영향이 없다.
- 넷째가 합류하는 순간 레벨 업 보상처럼 꼭 고르는 칸이 뜬다 (브리타와 리네가 한꺼번에 합류해 다섯이 되면 셋이 될 때까지 거듭 뜬다 — *제 판단*): "일행은 셋까지 — 쉼터에 남을 동료를 고르세요". 고른 동료는 「쉼터에서 기다린다」(이미 있는 상태)가 된다.
- 일행 탭에서 쉼터와 일행을 바꿀 수 있다 (지금처럼 쉴 수 있는 곳에서만). 일행이 셋이면 「데려가기」가 잠기고 이유가 보인다.
- 쉼터의 동료는 큰 이야기 전투에 손님으로 오는 기존 규칙(`guestsIf`)을 3장 결전에 쓴다 — 이야기에 꼭 필요한 동료(오르덴의 결말 전투의 오르덴 등)는 일행에 없어도 그 자리에 있다.

## 6. 기존 동료의 3장 (운명표 3장 칸)

| 동료 | 상태 | 3장 |
|---|---|---|
| 오르덴 | 함께 | 맹세의 전당에서 결말: **맹세를 끝낸다**(`orden_released`, 돌의 몸이 풀려 사람으로 — 계속 동료, 수호는 잃고 명중·피해가 오른다. 수치는 만드는 사람이 정함) / **왕도의 마지막 문으로 남는다**(`orden_stays`, 일행을 떠나 5장에 돌아옴) / **유령 기사들에게 흔들린다**(`orden_cracked`이거나 유대 낮음 → 그를 붙잡는 전투, 지면 `orden_fell`) |
| | 헤어짐 | 맹세를 깬 경우(`orden_oath_broken`) 이르반의 흔적을 쫓아 왕도에 먼저 와 있다. 전당에서 다시 만나 같은 결말 선택 |
| | 관문에 남음 (`orden_joins` 없음) | 관문으로 돌아가 왕도 이야기를 들려주면 북쪽으로 따라온다 |
| | 죽음 | 전당의 카이론 석상 앞에 그의 장창을 바칠 수 있다. 메아리가 그 사실을 비웃는다 |
| 세나 | 함께·쉼터 | 리네와 함께 왕도의 문을 연다 (물길 읽기) |
| | 헤어짐 | 호수 기슭 숲에서 길잡이로 다시 만난다 (곧바로 합류) |
| | 떠남 | 사과하면 합류, 아니면 리네의 원수(데인)를 쫓아 따로 움직이다가 물의 문 전투에 끼어든다 |
| | 적 | 왕도의 사냥단을 이끈다. 리네가 있으면 리네가 말리는 판정, 없으면 싸움·설득·비킴 |
| | 죽음 | 리네가 있다면 리네가 그대를 따르지 않는다 (리네 합류 안 됨). 노파의 등불이 판정 하나에 불리 |
| 브란 | 함께·쉼터 | 서고의 낙인 기록 해독 (판정 유리, 카델 단서를 더 많이 얻음) |
| | 헤어짐 | 브리타와 함께 갈대 나루의 피난민을 돕고 있다. 찾아가면 합류 |
| | 떠남 | 서고에서 낙인 기록을 혼자 불태우려다 그대와 부딪친다 (설득·싸움·두기) |
| | 적 | 데인의 사냥개로 물의 문에 다시 나온다. 브리타가 있으면 마지막 설득 |
| | 죽음 | 브리타가 그대를 원망한다. 합류는 매력 판정 |

- 운명표의 규칙(두 번 적으로 만들면 세 번째에는 설득 없음, 쓰러짐은 되돌릴 수 없음)을 따른다.

## 7. 전투와 적

새 적 (이름은 가안):

## 10. 접근 방법

1. **2장과 같은 방식으로 `chapter3.js`를 덧붙인다 (택함).** 1·2장이 이미 쓰는 데이터 형식(장소·사건·적·아이템·동료)과 엔진 기능을 그대로 쓰고, 엔진에는 일행 제한과 그림만 더한다. 검사기·자동 플레이도 그대로 늘려 쓴다.
2. 엔진을 장별 모듈로 크게 나눈 뒤 3장을 쓴다 — 지금 구조가 2장까지 잘 버티고 있어서 이번 장에 들일 까닭이 없다.
3. 3장을 짧은 맛보기(장소 둘·우두머리 하나)로 먼저 낸다 — 사용자가 2장 규모를 기대하고, 운명표·새 동료·일행 제한이 다 맞물려야 의미가 있어서 맞지 않는다.
