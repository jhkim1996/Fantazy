# 떨어진 별의 노래

주사위로 진행하는 판타지 RPG. 브라우저에서 `index.html`을 열면 바로 플레이할 수 있다.

- **제1장 「비 내리는 관문」**: 서장 + 10개 장면 (`chapter1.js`)
- 선택지마다 성공·실패 결과가 미리 정해져 있고, **어떤 결과든 다음 장면으로 이어진다.**
  결과는 플래그와 오르덴과의 유대 수치로 남아서 뒤 장면의 문장, 난이도, 열리는 선택지를 바꾼다.
- HP가 0이 되어도 게임 오버는 없다. 쓰러졌다가 일어나고, 그 횟수가 기록된다.
- 진행 상황은 브라우저(localStorage)에 자동 저장된다. `처음부터 다시`는 두 번 눌러야 초기화된다.

## 판정

`d20 + 능력치 (+ 보정) ≥ DC`면 성공. 20이 나오면 무조건 대성공(따로 정한 결과가 없으면 경험치 +1), 1이 나오면 대실패.

- **마력 증폭**: 기력을 써서 판정에 d4(낡은 지팡이) 또는 d8(별빛 지팡이)을 더한다.
- **레벨 업 스킬** (하나씩 고름): 예지의 눈(d20 두 번), 집중(증폭 비용 1), 행운의 별(1을 10으로).

## 1장의 갈림길

| 선택이 남기는 것 | 나중에 바뀌는 것 |
|---|---|
| 노파의 전승 (`lore`) | 관문 룬 해독 +2, 맹세 구절 +3 |
| 옛 수로의 길 (`shortcut`) | 계단을 피하는 선택지가 열림 |
| 사냥개의 경계 (`alerted`) | 숨기·룬 덫 난이도 상승 |
| 회색 낙인의 비밀 (`mark_seen`) | 우두머리를 죽이지 않고 해방하는 결말이 열림 |
| 오르덴과의 유대 (`bond`) / 맹세 (`oath`) | 투창·의식·합동 돌격이 열림, 2장 동행 여부 |
| 새끼를 품에 안음 (`pup_safe`) | 결말에서 새끼가 동료로 남을 수 있음 |

우두머리 잿빛 송곳니의 운명(쓰러뜨림 / 해방 / 도주), 오르덴의 동행 여부, 사냥꾼이 그대를 알아챘는지는 1장 끝 화면에 정리된다.

## 장면 작성 형식

```js
n3: {
  title: '울음의 관문',
  clock: '관문의 룬을 읽어 문을 깨운다',
  text: ['항상 나오는 문단', { if: { flag: 'alerted' }, t: '조건이 맞을 때만 나오는 문단' }],
  choices: [
    { id: 1, label: '룬을 해독한다', stat: '지혜', dc: 13,
      bonus: [{ if: { flag: 'lore' }, v: 2, why: '노파의 전승' }],   // 판정 보정
      dcMod: [{ if: { flag: 'alerted' }, v: 2, why: '경계 중' }],    // DC 보정
      requires: { min: { bond: 1 } }, reqText: '오르덴의 신뢰',       // 조건이 안 되면 잠김
      success: { text: [...], fx: { xp: 1, add: { bond: 1 } }, log: '...', next: 'n4' },
      fail:    { text: [...], fx: { hp: -3, set: ['wary'] },   log: '...', next: 'n4' },
      crit:    { ... } },                                            // 선택: 20일 때 결과
    { id: 2, label: '판정 없이 진행', roll: false, then: { text: [...], next: 'n4' } }
  ]
}
```

- **조건** (`if`, `requires`): `flag`, `not`, `any`, `min`, `max`, `item`, `skill`, `or`, `nor`
- **효과** (`fx`): `hp`, `mp`, `hpFull`, `mpFull`, `xp`, `items`, `drop`, `set`, `unset`, `add`, `amp`, `stats`
- `fxIf: [{ if, fx }]`는 기본 효과를 적용한 뒤 조건을 보고 추가로 적용한다.

다음 장 파일에서 `carryFrom: 'fallen-star-ch1'`을 지정하면, 1장을 끝까지 마친 기록(레벨, 스킬, 소지품, 플래그, 유대)을 이어받아 시작한다. `index.html`의 `<script src="chapter1.js">`만 바꾸면 된다.
