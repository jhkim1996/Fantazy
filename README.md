# 떨어진 별의 노래

주사위로 진행하는 오픈월드 판타지 RPG. 브라우저에서 `index.html`을 열면 바로 플레이할 수 있다.

- `index.html` — 화면 (레이아웃, 스타일)
- `game.js` — 엔진 (모험가 만들기, 지도, 이야기 판정, 턴제 전투, 저장)
- `art.js` — 장면 그림 (캔버스 실루엣 일러스트, 날씨, 전투 효과)
- `chapter1.js` — 제1장 「비 내리는 관문」 데이터 (장소, 사건, 적, 아이템, 기술)

진행 상황은 브라우저(localStorage)에 자동 저장된다. 전투 도중에 닫아도 이어서 할 수 있다.

## 흐름

1. **모험가 만들기** — 능력치(4d6 굴림 또는 20포인트 구매) → 종족 → 직업 → 배경 → 이름.
2. **지도** — 장소 사이를 자유롭게 오간다. 장소마다 할 수 있는 일이 다르다.
   - ★ 이야기: 주 이야기가 기다리는 곳 (지도에 ★ 표시)
   - 사냥한다: 그 장소의 적과 전투 (경험치·금화·전리품)
   - 탐색한다: 작은 사건(주사위 판정)이나 전투
   - 쉰다: 마을, 오르덴이 깨어난 뒤의 관문에서 HP·마력 모두 회복
   - 상점: 마을의 행상인 (물약, 무기, 갑옷)
   - 이동하면 가끔 매복을 당한다.
3. **이야기 사건** — 선택지마다 성공·실패 결과가 정해져 있고, 어떤 결과든 이야기는 이어진다. 결과는 플래그와 오르덴과의 유대로 남아 뒤의 문장·난이도·선택지·전투를 바꾼다.
4. **턴제 전투** — 모든 행동이 주사위다.
5. **1장 끝** — 기록 화면이 나오고, 그 뒤에도 세계를 계속 돌아다니며 사냥할 수 있다.

## 판정 (발더스 게이트 3에서 가져온 아이디어)

- **기술과 숙련**: 14개 기술(운동·곡예·손재주·은신·비전·역사·지각·통찰·생존·의학·설득·기만·위협·공연). 직업·배경·종족에서 숙련을 얻으면 숙련 보너스(+2, 레벨 5부터 +3)를 더하고, 두 곳에서 겹치면 전문(두 배). 이야기 선택지에 `[설득]` 같은 꼬리표가 붙는다.
- **유리/불리**: 상황에 따라 d20 두 개를 굴려 높은 값/낮은 값. 노파의 전승이 있으면 룬 해독이 유리, 사냥개가 경계 중이면 숨기가 불리, 얼어붙거나 연막 속인 적은 공격이 유리, 중독되면 공격이 불리.
- **성공 확률**: 모든 선택지와 공격에 % 표시. 증폭을 켜면 바로 다시 계산.
- **영감**: 배경다운 선택(군인은 정면으로 맞설 때, 학자는 옛 지식을 파고들 때…)을 하면 쌓인다(최대 4). 이야기 판정에 실패하면 영감 하나로 다시 굴릴지 고른다.
- **업보 주사위**(설정에서 끄고 켬): 두 번 연달아 실패하면 다음 판정이 유리.

## 종족과 배경

| 종족 | 점수 보너스 | 특성 |
|---|---|---|
| 인간 | 모두 +1 | — |
| 엘프 | 민첩 +2, 지혜 +1 | 지각 숙련 |
| 드워프 | 힘 +2, 지혜 +1 | 레벨마다 HP +1, 독 피해 절반 |
| 하플링 | 민첩 +2, 매력 +1 | d20에서 1이 나오면 한 번 다시 굴림 |

| 배경 | 숙련 | 영감을 얻는 때 |
|---|---|---|
| 군인 | 운동, 위협 | 정면으로 맞서거나 누군가를 지킬 때 |
| 학자 | 비전, 역사 | 옛 지식과 룬을 파고들 때 |
| 떠돌이 악사 | 공연, 설득 | 노래와 이야기로 마음을 움직일 때 |
| 부랑아 | 손재주, 은신 | 몰래, 재빠르게 남의 눈을 피할 때 |
| 순례자 | 통찰, 의학 | 자비를 베풀거나 죽은 이를 기릴 때 |
| 사냥꾼 | 생존, 지각 | 짐승을 읽고 자연의 흐름을 따를 때 |

## 그림

장소·사건·전투마다 화면 위에 실루엣 그림이 그려진다(비, 안개, 별, 먼지 같은 날씨 포함). 전투에서는 공격하는 쪽이 달려들고, 맞은 쪽이 흔들리며 피해 숫자가 떠오른다. 그림의 적을 눌러 대상을 고를 수 있고, 전투 중에는 그림이 화면 위에 붙어 있다. 움직임 줄이기 설정을 켠 기기에서는 정지 그림만 그린다.

## 지도

| 장소 | 적 레벨 | 열리는 조건 | 할 일 |
|---|---|---|---|
| 마지막 마을 | 안전 | 처음부터 | 노파(이야기·부탁), 휴식, 상점 |
| 안개 비탈 | 1~2 | 처음부터 | 늑대·박쥐·멧돼지 사냥 |
| 검은 소나무 숲 | 2~3 | 처음부터 | 거미·멧돼지·이끼 곰 사냥 |
| 천 개의 계단 | 2~3 | 처음부터 | 첫 방문 시 정찰병 사건, 사냥개 사냥 |
| 옛 수로 | 3~5 | 노파의 지도 해독 성공 | 거머리, 물에 잠긴 기사(엘리트), 비밀 길 |
| 울음의 관문 | 안전 | 처음부터 | 첫 방문 시 오르덴 사건, 오르덴과 쉬기 |
| 별의 무덤 | 3~4 | 오르덴을 깨운 뒤 | 별의 유물 → 사냥개의 밤 (권장 레벨 3) |
| 무너지는 회랑 | 4~6 | 사냥개의 밤 이후 | 사냥개·추종자 사냥, 잿빛 송곳니 결전 (권장 레벨 5) |

부탁: 노파의 늑대 사냥, 오르덴 동생의 반지(옛 수로의 물에 잠긴 기사), 회색 낙인 조각 3개 모으기.

## 전투

- **공격**: `d20 + 대표 능력치 + 레벨/2 + 무기 보너스 ≥ 적 방어`면 명중. 피해는 무기 주사위 + 대표 능력치. 20(무기에 따라 18~19도)은 치명타로 피해 주사위 두 배, 1은 언제나 빗나감.
- **기술**: 마력을 쓴다. 직업마다 레벨 1·3·5에 익힌다.

  | 직업 | 레벨 1 | 레벨 3 | 레벨 5 |
  |---|---|---|---|
  | 마법사 | 마력 탄 | 서리 사슬 (얼림) | 별불 (전체) |
  | 전사 | 강타 | 전투 함성 (버프) | 회오리 베기 (전체) |
  | 도적 | 급소 찌르기 | 연막 (적 불리) | 독칼 (독) |
  | 음유시인 | 불협화음, 치유의 노래 | 전장의 찬가 (버프) | 별의 노래 (전체+회복) |

- **물품**: 은빛 물약(HP 15), 푸른 물약(마력 8).
- **방어**: 그 턴 받는 피해 절반, 마력 +1.
- **도망**: `d20 + 민첩 ≥ 10 + 적 레벨` (이야기 전투에서는 못 도망친다).
- **적의 차례**: `d20 + 적 명중 ≥ 그대의 방어(10 + 민첩 + 방어구)`.
- **지면**: 사냥에서 지면 가까운 쉼터에서 깨어나고 금화 1/4을 잃는다. 이야기 전투에서 지면 진 결과로 이야기가 이어진다.

## 성장

- 레벨 업: 직업별로 최대 HP·마력이 오르고 모두 회복. 그리고 **능력치 +1** 또는 **재능**(예지의 눈 / 집중 / 행운의 별) 중 하나를 고른다.
- 필요 경험치: 12, 24, 40, 60, 84, 112 … 이야기만으로는 부족해서 사냥이 필요하다.
- 자기보다 레벨이 3 이상 낮은 적은 경험치가 절반이다.
- 장비는 더 좋은 것을 얻으면 자동으로 착용한다.

## 데이터 형식 (`chapter1.js`)

```js
locations: {
  slope: { name, x, y, lv: '1~2', if: {조건}, desc: [...],
    encounters: [{ w: 4, e: ['wolf'] }, { w: 2, e: ['wolf', 'wolf'] }], ambush: 0.2,
    explore: ['ex_glint'], actions: [{ label, event, if, star }], onEnter: [{ event, if }],
    rest: '쉬는 문구', restIf: {조건}, shop: { name, items: [...] },
    links: [{ to: 'village' }] } },
enemies: { wolf: { name, lv, hp, ac, atk, dmg: '1d6+1', xp, gold: [2, 6], drops, skills, poison, drain } },
events: {
  n3: { title, clock, text: [...], choices: [
    { id: 1, label, stat: '지혜' | 'class', dc: 13, bonus, dcMod, requires, reqText, note,
      success: { text, fx, fxIf, log, next: 'n4' | 'map' | 'end', battle: { enemies, win, lose, ... } },
      fail: {...}, crit: {...} },
    { id: 2, label, roll: false, then: {...} } ] } }
```

- **판정 선택지**: `stat`(능력치 또는 `'class'`), `skill`(기술), `dc`, `adv`/`dis`(`[{ if, why }]` 유리·불리), `insp`(배경 영감 꼬리표: brave·lore·song·sly·mercy·wild), `bonus`/`dcMod`.
- **그림(art)**: `{ sky: 'rain'|'dusk'|'night'|'dawn'|'star'|'cave', bg: 'village'|'slope'|'forest'|'stairs'|'gate'|'aqueduct'|'tomb'|'hall'|'barrier'|'hut'|'mountains', props: [...], actors: [{ k: 'hero'|'orden'|'crone'|'hound'|'alpha'…, x: 0~1 }], fx: ['rain','fog','stars'…] }`. 배열로 주면 `if`가 맞는 첫 그림을 쓴다. 장소·사건·이야기 전투에 붙인다.
- **조건**: `flag`, `not`, `any`, `min`, `max`, `item`, `count`, `skill`, `cls`, `or`, `nor`. 사건을 마치면 `done_<사건 id>`가 켜진다.
- **효과(fx)**: `hp`, `mp`, `hpFull`, `mpFull`, `xp`, `gold`(숫자 또는 `[최소, 최대]`), `items`, `drop`, `set`, `unset`, `add`, `amp`, `stats`.
- **이야기 전투(battle)**: `enemies`, `win`/`lose` 결과, 선택적으로 `mods`(플래그에 따라 적 약화), `ally`(함께 싸우는 동료), `hesitate`, `special`(조건부 특수 행동), `noFlee`.
- **직업별 문장**: `{ mage, warrior, rogue, bard, _: 기본 }`. **낱말 치환**: `{name}` `{cls}` `{weapon}` `{item}` `{fine}` `{relic}` `{amp}`, 조사 `{item:을}`. **수치**: `{#kill_wolf}`, `{@회색 낙인 조각}`.
